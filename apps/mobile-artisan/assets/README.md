# Assets

Placez ici les fichiers suivants avant un build EAS production :

- `icon.png` (1024×1024)
- `splash.png` (1284×2778 recommandé)
- `adaptive-icon.png` (1024×1024, Android)
- `notification-icon.png` (96×96, monochrome)

Pour le développement local, des placeholders minimaux sont générés automatiquement.
